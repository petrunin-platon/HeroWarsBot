# Редизайн интерфейса RPA BOT v1.6.1 — задание для Claude Code

Эта папка — дизайн нового интерфейса бота **Hero Wars: Knowledge Engine Bot**.
Задача: переделать **только интерфейс** на CustomTkinter по этим макетам. Логику бота
(компьютерное зрение, машина состояний, правила, ADB/scrcpy, Telegram) **не трогать**.

## Как устроен бот сейчас (не ломать)

- **Движок и окно — отдельные процессы.** Они обмениваются специальными командами через терминал: так окно узнаёт о событиях, просит показать окно вмешательства или отправить сообщение в Telegram. Этот механизм **оставить как есть**. Новые кнопки отправляют те же команды, что и старые.
- **Окно обновляется только из главного потока Tk.** Сообщения от движка складывай в очередь, а окно забирает их раз в ~100 мс через `after()`. Не трогать виджеты из других потоков: от этого Tkinter подвисает и падает.
- **13 языков — через `i18n.py`.** Все надписи нового интерфейса берутся из этого словаря по ключу, **ни одной русской строки прямо в коде виджетов**. У кнопок с текстом не задавать жёсткую ширину: немецкие и испанские надписи бывают длиннее русских на треть. Проверь каждый экран на самом длинном языке.

## Железные правила

1. **Меняем только слой интерфейса.** Если кнопке не хватает функции в ядре — оставь заглушку с `TODO` и напиши об этом, не придумывай логику.
2. **Размер окна.** По умолчанию 1100×720, если экран позволяет; иначе окно уменьшается под экран (с учётом масштаба Windows и панели задач). **Минимум 1000×620**, пользователь может менять размер. Шапка (56 px) и футер (64 px) всегда на месте, при нехватке места прокручивается только середина (`CTkScrollableFrame`). Карточки тянутся по ширине через `grid` с весами.
3. **Без эмодзи.** Tkinter в Windows рисует их плохо. Везде иконки из `icons/`.
4. **Без rgba.** Tk не умеет полупрозрачность. Подкрашенные фоны уже посчитаны в `theme.TINTS` / `ELEMENTS[...]["tint"]`, для новых — `theme.blend()`.
5. **Зелёный — только старт и сохранение.** `green` — большая «Начать фарм»; `green_button` — «Сохранить …», «Применить». Остальные действия — синие (`blue_button`) или нейтральные.
6. **Синий — выбранное.** Активный пункт меню, выбранный сегмент, включённый тумблер, прогресс.
7. **Красный текст — `danger_text`** (#F87171), а не #EF4444.
8. **Титаны — квадраты 36×36, а не текст.** Рамка 2 px цветом стихии, фон — `tint` стихии, внутри картинка (или две буквы имени, пока картинок нет), подсказка с именем при наведении.
9. **Опасные действия — только с подтверждением** (экран 8): «Очистить все правила», «Восстановить / Сброс», «Очистить журнал». Уход со страницы мастера правил с несохранёнными изменениями — диалог «Сохранить изменения?».
10. Надписи — с большой буквы только первое слово («Правила и перехваты»).

## Экраны — что важно

**1. Главная — четыре состояния** (в макете переключаются в Tweaks → «Состояние»):
- *Первый запуск* — вместо конфигурации чек-лист «С чего начать»: 1) подключи телефон (текущий шаг подсвечен синим), 2) проверь паки (ссылка в мастер правил), 3) Telegram по желанию. Журнал — пустое состояние с подсказкой.
- *Не подключён* — конфигурация запуска + синяя «Подключить телефон».
- *Готов к старту* — конфигурация (Цель сессии, Режим, Порог паники ХП, Сброс дня) + зелёная «Начать фарм» и подпись «Окно свернётся в мини-бар под игрой».
- *Фарм идёт* — слева «Текущая сессия»: титанит за сегодня с прогрессом, этаж и дверь, бои (побед из всего), время сессии; справа «Свернуть в мини-бар», а «Пауза F9» и «СТОП F10» активны.

Правая колонка 308 px той же высоты, что и левая, отделена линией. Пауза и стоп неактивны (бледные), пока бот не работает. Ниже журнал с фильтрами «Все / Бои / Правила / Система / Ошибки (N)».

**2. Док-плеер (HUD).** Окно без рамки (`overrideredirect(True)`, поверх остальных), высота 60, ширина = ширине окна scrcpy.
- Стоит **вплотную под клиентской областью** окна `HeroWarsBot_Arena`: координаты через WinAPI `GetClientRect` + `ClientToScreen`, а не по рамке окна (у Windows 10/11 невидимая рамка ~7 px).
- **Ездит за окном scrcpy:** раз в ~500 мс проверяет его положение и ширину и встаёт под него.
- **Не перекрывает картинку игры ни на пиксель**, иначе попадёт на скриншот для OpenCV.
- Колонки 15% / 25% / 40% / 20%: статус + этаж; титанит с прогрессом `blue`; две строки журнала (последнее событие с цветной меткой и временем + предыдущее серым); 4 кнопки 38×38.
- SOS: фон `sos_bg`, красная рамка.

**3. Мастер правил** — три вкладки и общий футер («Все изменения сохранены» / «Есть несохранённые изменения», «Восстановить / Сброс», «Сохранить настройки»). Профилей нет — не добавлять.
- *База и комнаты:* «Цели и лимиты», «Безопасность и режим», 4 строки стихий: иконка, основной пак из 5 аватаров + карандаш (окно «Собери состав»), раскрывающиеся «Запасные паки N шт.», кнопка «+ Условие» (окно нового правила с этой стихией).
- *Авто-тактика и ХП:* синяя плашка-подсказка; «Приоритет дверей» — 4 места со стрелками, **каждое место — выпадающий список стихии** (перетаскивания нет: в Tkinter оно ненадёжно). Выбрал стихию, которая уже стоит на другом месте, — они меняются местами. Далее «Критерии плохого боя и SOS», «Авто-сборка пака отхила», «Личные пороги паники» (чипсы с ✕ и «Задать личный порог титану»).
- *Правила и перехваты:* ряд 1 — «Активные правила», счётчик, справа серая подсказка; ряд 2 — фильтры стихий и **справа в том же ряду** «+ Новое правило» (второстепенная, высота 30). Затем шапка колонок «№ · Условие · Действие · Вкл.» и прокручиваемый список. В строке: ↑↓ с номером, бейджи стихии и типа, название, условие серым, действие (аватары пака или бейдж), **тумблер вкл/выкл** (выключенное правило бледное, но не удалено), карандаш и ✕. Правила, созданные ботом, получают понятное имя вида «Авто: Ангус + Араджи в комнате».

**3d. «Новое правило»** (`CTkToplevel` 560×660): стихия, название, триггер «По ХП / По энергии / По врагам» (враги — сетка 7 колонок из 13 титанов с галочками), действие (2 галочки + обкатка), состав (5 аватаров + «Выбрать состав»), «Отмена» / «Сохранить правило».

**3e. «Собери состав»** (`CTkToplevel` 900×580): 5 слотов сверху (клик убирает), «Выбрано: N / 5» и статус (жёлтый «Минимум 3 · нужно ещё K» / зелёный «Можно применять»), 5 колонок по стихиям из `theme.TITANS`, выбранный — зелёная рамка и галочка, при 5 выбранных остальные заблокированы; «Применить» неактивна, пока меньше трёх.

**4. Аналитика.** Три показателя (боёв, винрейт с кольцом, «золотые правила» золотым), колонки «Золотые правила» (пустое состояние / карточки с галочками) и «Ход анализа», внизу «Запустить анализ логов» и «Внедрить золотые правила (N)».

**5. Статистика.**
- Над плитками слева подсказка, справа «Период».
- Шесть плиток: цифры белые, цвет только у иконок.
- **Клик по столбику графика выбирает день:** плитки показывают цифры за этот день («Титанит за день», «От дневной нормы», зелье, комнаты, этажи, правила), столбик подсвечен, остальные бледнее. Слева появляется синяя плашка «Показан день: 19 октября ✕» — клик по ней возвращает итоги. Повторный клик по выбранному столбику тоже сбрасывает выбор. «Ручная корректировка» подставляет выбранный день.
- График на `tk.Canvas`: столбики `green`, значения над ними, пунктир дневной нормы, подсказка при наведении.

**6. Руководство** — рисуется из Markdown по правилам `GUIDE_FORMAT.md`. Файлы `guide/<код языка>.md`; если для языка файла нет — показывать `en.md`, затем `ru.md`. Оглавление слева строится из заголовков `##`, клик прокручивает к разделу.

**7. О программе.**
- Верхняя карточка: иконка, название, `v1.6.1`, `Beta`, слоган, описание в заполненной плашке.
- Справа 4 кнопки: «Проверить обновления», «Папка бота», «Написать автору» (синяя), «GitHub проекта».
- «Автор и лицензия» и «Состояние компонентов» — одинаковые полосы высотой 36 на одном уровне.
- Донаты: адреса показываются сокращённо, копируется полный адрес из кода.

**8. Диалоги и состояния** — образцы подтверждения удаления, «Сохранить изменения?», состояний поля и уведомлений.

## Порядок работы (после каждого шага — запуск и сверка со скриншотом)

1. `theme.py` и `icons/` в пакет интерфейса (например `ui/theme.py`, `ui/icons/`). Общие виджеты: `Card`, `IconButton`, `Tooltip`, `TitanAvatar`, `Chip`, `ConfirmDialog`, `Toast`.
2. Каркас: окно с умным размером, сайдбар-полоска, шапка, переключение пустых страниц, горячие клавиши.
3. Главная (4 состояния) и журнал.
4. Док-плеер, следование за scrcpy, переход «Начать фарм» ⇄ «Развернуть».
5. Мастер правил, окна «Новое правило» и «Собери состав», диалоги подтверждения.
6. Аналитика и Статистика (с выбором дня).
7. Руководство (Markdown-рендер) и О программе.

Перед каждым шагом коротко напиши план, после — что сделано и что осталось. Старый интерфейс не удаляй, пока новый экран не заработает.
