# Как писать руководство в Markdown, чтобы в боте было красиво

Идея простая. Ты пишешь обычный текстовый файл с небольшой разметкой — как заметку в Obsidian.
Бот читает этот файл и превращает каждую разметку в готовый «кирпичик» интерфейса:
заголовок становится пунктом оглавления, нумерованный список — карточками шагов,
цитата с пометкой — цветной плашкой. Оформление (цвета, отступы, шрифты) задаёт бот,
а ты думаешь только о тексте.

Плюсы такого подхода:
- текст правится без программиста и без пересборки интерфейса;
- на 13 языков — просто 13 файлов: `guide/ru.md`, `guide/en.md`, `guide/de.md` и так далее (имя файла = код языка из `i18n.py`);
- в Obsidian файл тоже выглядит прилично: плашки `> [!tip]` и другие Obsidian понимает сам.

## Что пишешь → как выглядит в боте

| Пишешь | В боте |
|---|---|
| `# Руководство пользователя` | Большой заголовок вверху. Один на файл. |
| Обычный текст | Абзац. Пустая строка — новый абзац. |
| `## Как подружить телефон и компьютер` | Новый раздел: заголовок с подписью «РАЗДЕЛ N» и пункт в оглавлении слева. Номер ставится сам. |
| `**жирный**` | Жирный текст. |
| `«Подключить телефон»` | Названия кнопок и пунктов меню пиши в «ёлочках» — так их легко узнать. |
| `` `adb devices` `` | Моноширинный текст: команды, имена файлов. |
| `- пункт` | Список с синими точками. |
| `- :eye: пункт` | Список с иконкой вместо точки. Имя иконки — как файл в `design/icons` без `.png`. |
| `1. **Заголовок шага** — текст шага` | Карточка шага с синим номером. Шаги подряд встают сеткой по 2 в ряд. |
| `> [!tip] текст` | Тёмная плашка-подсказка. Если стоит сразу под шагом с отступом — попадает внутрь карточки шага. |
| `> [!note] текст` | Синяя плашка «Как это работает». |
| `> [!warning] текст` | Жёлтая плашка «Внимание». |
| `> [!done] текст` | Зелёная плашка «Готово» — ставь в конце раздела. |
| `![Подпись](images/usb.png)` | Картинка на всю ширину с подписью снизу. Картинки лежат в `guide/images/`. |
| `[Следующий раздел →](#2)` | Ссылка: прыжок к разделу №2. |
| `---` | Тонкая разделительная линия. |

Всё, чего нет в таблице, бот покажет как обычный текст — ничего не сломается.

## Правила, чтобы читалось легко

1. Один раздел — одна задача («Подключить телефон», «Настроить паки»).
2. Шаги — глаголом в начале: «Включи…», «Подключи…», «Нажми…».
3. В шаге 1–3 предложения. Длиннее — раздели на два шага.
4. Подсказки (`[!tip]`) — только то, что помогает, если что-то пошло не так.
5. В конце раздела — `[!done]`: что должно получиться и куда идти дальше.

## Для Claude Code: как это отрисовать

- Модуль `ui/guide_renderer.py`. Разбор — построчный (своими силами) или через `markdown-it-py` с разбором токенов. HTML-движки внутри Tk не использовать.
- Каждая конструкция из таблицы → виджет в стиле экрана `06_guide.dc.html`. Цвета и шрифты брать из `theme.py`, иконки — из `icons.icon()`.
- Оглавление строится из `##`. Клик по пункту прокручивает `CTkScrollableFrame` к разделу, активный пункт подсвечивается синим.
- Нумерованные шаги, идущие подряд, — сетка 2 колонки. Плашка `[!tip]` с отступом под шагом — внутрь карточки шага.
- Картинки масштабировать по ширине области текста (`CTkImage`), подпись — серым мелким шрифтом.
- Язык: `guide/<lang>.md`, если файла нет — `en.md`, затем `ru.md`.
- Файл перечитывать при каждом открытии вкладки, чтобы правки текста были видны без перезапуска.
