# Hero Wars RPA Bot v1.0 完全ユーザーマニュアル

やあ！Hero Warsの自動化システムへようこそ。

最初にハッキリさせておこう。このボットは、ただ画面を無闇にクリックするだけのバカなプログラムじゃない。君の専属の賢いアシスタント（RPAエージェント）だ。ゲーム画面を「見て」、タイタンのHPを評価し、統計を集め、ダンジョン攻略中にその場で戦術的な判断を下すことができるんだ。

素材集め（ファーム）を楽に、安全に、そして最大の資源を獲得できるようにするための設定方法を、ステップバイステップで解説していくよ。



## セクション1. スマホとパソコンを連携させる方法

ボットは専用の画面ミラーリングソフト（scrcpy）を使ってゲームを操作する。ボットに操作を任せるには、まずスマホ側で一度だけ設定を行う必要があるよ。

* **「USBデバッグ」を有効にする:** Androidスマホの設定 -> 開発者向けオプションを開き、「USBデバッグ」をオンにする。「開発者向けオプション」が表示されていない場合は、「端末情報」にある「ビルド番号」を7回タップしてね。
* **ケーブルで接続する:** 質の良いUSBケーブルでスマホとPCを繋ぐ。スマホの画面に「このパソコンからのUSBデバッグを許可しますか？」と表示されるので、「常に許可する」にチェックを入れて「OK」をタップする。
* **ゲームを起動する:** Hero Warsを開き、ダンジョンに入って通路（次の扉が見える場所）で立ち止まる。
* **ボットを接続する:** ボットのソフトのウィンドウで「1. スマホを接続」ボタンを押す。PCの画面にスマホの画面が表示されるよ。

**➡ 最重要ルール:** ボットは君と同じように、デジタルな「目」でゲームを見ている。ゲームのミラーリング画面は常にPCのモニター上に表示されていなければならない！ウィンドウを最小化したり、ブラウザで隠したり、画面の端に追いやって隠したりしちゃダメだ。画面が塞がれると、ボットは一時停止して、視界が元に戻るのを待つ状態になるよ。

**➡ 夜間の放置ファーム:** 夜間にボットを放置したいけどスマホの画面焼けが心配な場合は、コントロールパネルの「画面オフ」ボタンを使おう。スマホのディスプレイは消灯（黒く）なるけど、ゲーム自体は内部で動き続け、ボットもしっかり認識できるよ！



## セクション2. セッション目標（コントロールパネル）

ボットに「ギルドのノルマを達成するまで掘って、終わったら休んでね」と指示を出すことができる。「ルールマスター」タブを開いて、以下の目標を選択しよう：

* チタナイトの数（例：150で停止）
* 部屋の数（例：ちょうど10個の扉を攻略）
* 階数（2フロア分攻略）
* 時間（ちょうど30分間ファームする）

制限を設定したら、メインタブに戻って「2. ファーム開始」を押す。ボットが自動でウィンドウサイズを調整し、必要な編成を組んで戦闘へと走り出してくれるよ。



## セクション3. ルールマスター（ボットに思考を教える）

ダンジョンには「土」「水」「火」「混合」の4種類の部屋がある。ボットにただのクリック連打をさせるのではなく、ベテランプレイヤーのような判断をさせるために、属性ごとに個別のロジックを設定することができる。

**1. 基本編成（デフォルトパーティ）**

これは、ボットがデフォルトで使用する君のメイン編成だ。初期状態ではすべてのスロットが空になっているよ。

* 任意の属性の青いボタン（例：「水」）を押す。
* 開いたウィンドウで3〜5体のタイタンを選択する（通常は5体フル編成にする。例：ハイペリオン、シグルド、テティス、ノヴァ、マイリ）。
* 緑色の「適用」ボタンを押す。

ゲームが順調に進み、HPが正常に保たれている限り、ボットは常にこの編成で戦う。

**2. ルールコンストラクター（割り込み設定）**

時には状況がコントロールできなくなることもある。そのために用意されているのがルール（**「+ 条件を追加」**ボタン）だ。ボットは各扉に入る前に状況を評価し、編成を変更して操作を「割り込む（上書きする）」ことができる。ルールの名前は自分で自由に決められる。動作には影響せず、整理しやすくするためのものだ。

条件は以下の3つのタイプに分けられる：

* **HP基準:** 例えば、タンクのシグルドがよく瀕死になるとする。そんな時は次のようなルールを作成する：*「シグルドのHPが35%未満の場合、ヒーラー（イヤリ）入りの編成を選択する」*。最重要ルール：回復のための割り込みルールは、**そのタイタンが回復できる属性の部屋に設定すること！**（シグルドの場合は水または混合の部屋）。

* **エネルギー基準:** 「速攻」パーティにとって極めて重要。例えば、アングスが土の部屋で戦闘開始直後にスキル（ウルト）を撃って数秒で敵を全滅させ、敵に攻撃の隙を与えないとする。しかし、そのためにはエネルギーが溜まった状態で戦闘に入る必要がある。その場合は次のルールを作ろう：*「アングスのエネルギーが97%未満の場合、ボットを停止する」*。ボットは土の部屋まで来ると、アラート音を鳴らして一時停止する。そうすれば、君が手動で混合部屋に入り、アングスのエネルギーを溜め直すことができる。

* **敵基準（アンチパーティ）:** 敵のアラジ（味方を焼き尽くす厄介な奴）が大嫌いなら、次のようにルールを設定しよう：「敵にアラジがいる場合、専用のアンチ編成を繰り出す」。

**3. スマートオプション（スキップと試運転）**

ルールコンストラクターには、不慮の全滅を防ぐためのチェックボックスが用意されている：

* **部屋への進入禁止（スキップ）:** シグルドのHPが残り10%で、目の前に混合部屋があるとしよう。そこに入れば、シグルドは確実にやられてしまう。そこで「HP20%未満でスキップ（進入禁止）」にチェックを入れておく。ボットは削られたシグルドを確認すると、混合部屋をスルーして、彼を回復させられる水の部屋を探しに行くんだ。

* **タイタンの試運転を要求する:** 新しいゲーム日（デイリー更新）のスタートに超便利な機能！朝、タイタンたちのHPは100%だけど、エネルギーは0%だ。この状態でいきなり難易度の高い混合部屋に突っ込ませると、スキルを発動する前に倒されてしまう。「試運転」のチェックを入れると、ボットは「このタイタンは混合部屋に行く前に、まず自身の得意属性の部屋で簡単な戦闘を少なくとも1回行い、エネルギーを溜めること」と認識するようになる。

**4. 優先順位：どちらが優先されるか？**

シグルドのHPが低い一方で、敵には恐ろしいアラジが控えている場合、ボットはどうすべきだろう？
ボットは君のルールリストを、人間と同じように**厳密に上から下へと**読み込んでいく。

灰色の**「アクティブなルールの確認/削除」**ボタンを押すと、ボットのロジックが表示される。ボットは以下のように整理している：

1. **まず「スキップ（Skip）」ルール**（消耗したタイタンを戦闘に入らせない）。
2. **次にHPとエネルギーによる救済措置**。
3. **その後にアンチ編成（敵基準）**。
4. **そして最後に基本編成**（何の脅威もない場合）。

このウィンドウでは、矢印キー（上/下）でルールの順序を移動させることができる。リストの上にあるルールほど、ボットが最優先で従う。順序を変更した場合は、必ずその画面で緑色の**「変更を保存」**ボタンを押してね。

**5. 重要：ボットが設定を記憶する仕組み**

ボットのUIは、ハードディスクへの頻繁な書き込み負荷を抑え、超高速で動作するように設計されている。

1. ルールを設定したら、メイン画面にある**紫色の「プロファイルを保存」ボタン**を必ず押すこと。
2. 「ファーム」ボタンを押した際、ボットは**一度だけ**すべてのルールを読み込んでメモリ（RAM）にロードする。
3. ボットがすでにファームを実行している最中にルールを変更して保存しても、ボットはそれを認識しない！新しい設定を読み込ませるには、一度「ストップ」を押してから、再度「ファーム」を開始する必要がある。

**➡ 「復元 / リセット」ボタン:** 突然の停電やシステムクラッシュで設定ファイルが破損してしまった場合は、ファームを開始する前にこの赤いボタンを押しよう。ボットが自動的にバックアップから設定を復元し、元通りにしてくれる。

**6. アングスのグローバルコントロール**

メイン画面にある**「アングスのスキル手動制御（グローバル）」**のトグルスイッチには、非常に重要な意味がある。このボットは、人間顔負けの精度でアングスを操作できる。根の攻撃が最大のダメージを与えるのを正確に1.8秒待ち、直後にスキルをオフにする。このチェックがオンになっていると、基本編成だろうが割り込み編成だろうが、アングスが参加する**すべての戦闘**でこのテクニックが適用される。ただし、このオプションを有効にする前に、アングスのエネルギーが100%充電されていることを確認してから使用してね。

**開発者からの裏技：なぜボットは頻繁に一時停止するのか？そして100%完全自律化させる方法は？**

初期の起動時によくある状況：タイタンのHPは見た目的にはまだまだ余裕があるのに、ボットが頻繁にゲームを一時停止し、SOSウィンドウを表示してどうするか尋ねてくる。「理由もなくパニックになっている」ように見えるかもしれない。

その原因は、メイン画面にある**「HP損失デルタ」**の設定にある。
デルタ（差分）とは、1回の戦闘で急激かつ突発的に受けるダメージから守るための保護機能だ。例えば、デルタを30%に設定しているとする。タイタンがHP100%で部屋に入り、戦闘終了時に69%になっていた場合（31%の損失）、たとえ69%という数値が緑ゲージの安全圏であり生存にまったく問題なくても、ボットは即座に停止する。

**SOS画面での中断をなくし、ボットを完全に自律動作させる方法：**

1. **「デルタ」を緩める（おまかせモード）:** 頻繁に一時停止するのが煩わしく、タイタンの育成に自信があるなら、「HP損失デルタ」を最大100%まで上げてしまおう（実質的なオフ状態）。これでボットは1戦ごとのダメージ量を気にしなくなり、*「HPパニックしきい値」だけ*を基準にするようになる。つまり、HPが本当にクリティカルな最低ライン（例：25%未満）に達した時だけ停止するようになる。

2. **停止を経験値に変える:** SOSウィンドウが表示されるたびに、それは「ルールマスター」を開いて新しい条件（ルール）を作り、次回ボットがそのダメージを回避できるように学習させるチャンスだ。

3. **アナリティクスを活用する（完全自律への道）:** これが一番重要！プレイセッションが終わるたびに、必ず「アナリティクス」タブを開いてログ解析を実行しよう。ボットが自動的にパターンを検出し、**「黄金ルール」**（実証済みの必勝編成）を提案してくれる。あとは「導入」を押すだけだ。

**まとめ:** このような「黄金ルール」や手動設定の条件をボットに学習させればさせるほど、ボットが君に尋ねてくる回数は減っていく。時間が経てば、君のタイタンの育成状況に完璧にマッチした理想的なナレッジベースが構築され、ボットは**100%完全に自律化**するよ！



## セクション4. 全滅防止対策（HP設定とSOS機能）

ボットが勝手にタイタンを全滅（ロスト）させることはない。戦闘が終わるたびに、HPバーを細かくチェックしている。「ルールマスター」タブには、2つの主要なセキュリティ設定がある：

* **HPパニックしきい値（例：40%）:** 絶対的な最低ライン。戦闘後、いずれかのタイタンのHPが40%を下回ると、ボットは警告を発する。
* **HP損失デルタ（例：30%）:** 突発的なダメージへの保護。タイタンがHP100%で戦闘に入り、60%で終了した場合、40%を失ったことになる（これがデルタ）。1戦闘につき30%以上の損失を許容しない設定にしている場合、残りHPがまだ十分にあっても、ボットはゲームを一時停止する。

**SOSシステム（レスキューメニュー）：**
パニックやデルタが作動するか、あるいはタイタンが死亡した場合、ボットはゲームを一時停止し、3つの選択肢があるウィンドウを表示する：
* **手動で攻略する:** ボットは撤退して戦闘をリセットし、君自身が手動でその部屋を攻略できるようにする。
* **戦闘をリセットする:** ボットは戦闘をキャンセルし、別の編成を選んで再挑戦できるようにする。
* **無視する:** ボットに「問題ない、この損害は許容範囲だ。次の部屋へ進め」と指示する。



## セクション5. Telegram通知機能

ボットがファームしている間、お茶を飲みに行ったり散歩に出かけたりしても大丈夫。タイタンが瀕死になると、ボットがスクリーンショットと操作ボタンを君のTelegramへ直接送ってくれるんだ！

* **ステップ1:** Telegramで公式ボットの **@BotFather** を検索する。`/newbot` というコマンドを送り、ボットの名前を決めて、発行された長い `Token`（トークン）をコピーする。
* **ステップ2:** ボット **@getmyid_bot** を検索する。「Start」を押し、表示された数字の `Your user ID` をコピーする。
* **ステップ3:** ステップ1で作った君の新しいボットとのチャット画面に戻り、必ず **「START」** ボタンを押す。
* **ステップ4:** ボットのソフトで「ルールマスター」を開き、**「Telegram設定」**をクリックする。コピーしておいた Token と Chat ID を入力し、「適用」を押してから「プロファイルを保存」する。



## セクション6. アナリティクスと学習機能

ボットはバックグラウンドのログにすべての戦闘データを記録している。誰と戦って、どれだけHPが残ったのか。

「アナリティクス」タブを開き、「ログ解析を実行」を押そう。ボットは各編成の勝率（Win Rate）を計算する。もし特定の敵に対して80%以上の確率で安定して勝利できるパーティを見つけたら、それを**「黄金ルール」**として定義する。
「導入」を押せば、ボットはその必勝タクティクスを永久に記憶するよ！



## セクション7. 統計情報と同期機能

ボットは美しい統計データを記録してくれる。グラフを描画し、獲得したチタナイト、部屋数、ポーションをカウントする。

**ゲーム内時間に関する重要事項:**
Hero Warsの一日は朝の05:00にリセットされる。ボットが夕方の戦闘と深夜の戦闘を混同しないように、ルールマスターで「デイリーリセット時間」を必ず指定しておこう。

**スマート同期:**
例えば、朝にスマホを使って手動でプレイし、チタナイトを60集めたとする。そして夜にボットを起動した。ボットはどうやって全体の進捗を把握するんだろう？
すごく簡単だ！「統計」タブを開き、日付（今日）を選択し、ゲーム内で確認できる**チタナイトの「合計数」**（例：150）を入力欄に入力するだけ。ボットは賢いので、自分が稼いだ分の「90」を認識し、150からそれを差し引いて、君が手動で稼いだ「60」を統計データにきれいに統合し、その分の部屋数やポーションも計算してくれる。入力エラー防止機能も内蔵されており、ボットが自ら稼いだ数値よりも小さい値を入力することはできないようになっているよ。



## セクション8. PC用ショートカットキー

* **Ctrl + Q (ソフトポーズ/一時停止):** ボットは戦闘の途中でゲームを投げ出したりしない。きれいに敵を倒しきり、報酬を受け取ってから次の扉の前で停止し、指示を待つ。
* **Ctrl + Shift + Q (緊急停止):** ボットを瞬時に停止する。何らかの不具合やトラブルが起きた時に使ってね。
