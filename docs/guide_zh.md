# Hero Wars RPA 机器人 v1.0 完整用户手册

嗨！欢迎使用《英雄战争》(Hero Wars) 自动化系统。 

我们先说清楚：这个机器人可不是那种只会无脑狂点屏幕的傻瓜程序。它是你的专属智能助手（RPA代理）。它能“看懂”游戏画面、评估泰坦的血量（HP）、收集统计数据，并能在清理地牢（Dungeon）时实时做出战术决策。

让我们一步步来看看如何配置，让挂机刷资源变得既轻松又安全，还能把收益拉满！



## 第一部分：如何让手机和电脑“牵手”

机器人通过专用的投屏软件（scrcpy）来控制游戏。为了让机器人能接管操作，你需要对手机进行一次性设置。

* **开启“USB调试”：** 在安卓手机上，进入“设置” -> “开发者选项”，然后启用“USB调试”。如果“开发者选项”被隐藏了，请去“关于手机”里连续猛戳7次“版本号”。
* **连接数据线：** 用一根质量好的USB线将手机和电脑连接起来。手机上会弹出提示“是否允许从此电脑进行调试？”。勾选“始终允许”，然后点击“确定”。
* **进入游戏：** 打开《英雄战争》，进入地牢，停在走廊里（能看到下一扇门的地方）。
* **连接机器人：** 在我们软件的窗口中，点击“1. 连接手机”按钮。电脑屏幕上就会弹出你手机画面的窗口。

**➡ 最重要的规则：** 机器人是通过它的“数字眼睛”来观察游戏的，就像你亲眼在看一样。因此，投屏窗口必须一直显示在显示器上！千万不能最小化、不能被浏览器遮挡，也不能藏在屏幕边缘后面。如果窗口被挡住，机器人就会暂停并等待，直到你重新让它看清画面。

**➡ 夜间挂机：** 如果你想在晚上挂机，又不想让手机屏幕一直亮着（防止烧屏），可以使用控制面板中的“关闭手机屏幕”按钮。手机屏幕会熄灭（变黑），但游戏在后台依然正常运行，机器人也能看得一清二楚！



## 第二部分：挂机目标设置（控制面板）

你可以给机器人下达命令：“挖到满足公会每日要求为止，然后就去休息”。进入“规则大师”标签页并选择你的目标：

* 按**泰坦石数量**（例如：达到150个时停止）。
* 按**房间数量**（例如：刚好通关10个房间）。
* 按**层数**（例如：通关2层）。
* 按**时间**（例如：挂机刷满30分钟）。

设置好限制后，返回“主页”标签页并点击“2. 开始挂机”。机器人会自动调整窗口大小、配置好所需的阵容，然后直接冲进战场。



## 第三部分：规则大师（教机器人思考）

在地牢里有4种类型的房间：土、水、火和混合。为了让机器人不仅会盲目点击，还能像高玩一样思考，你可以针对每种属性单独配置逻辑。

**1. 基础阵容（默认队伍）**

这是你的核心主力阵容，机器人默认会使用它。初始状态下所有槽位都是空的。

* 点击所需属性的蓝色按钮（例如“水”）。
* 在打开的窗口中，选择3到5名泰坦（通常配置满员5人——例如：海波利恩、西格德、泰西斯、诺娃、迈利）。
* 点击绿色按钮“应用”。

如果游戏一切顺利且泰坦血量正常，机器人会一直使用这套阵容。

**2. 规则构建器（拦截/覆盖）**

有时候局势会失控。这时就需要用到规则（点击 **“+ 添加条件”** 按钮）。机器人在进入每扇门前都会评估状况，并在需要时通过更改阵容来接管控制。规则名称由你自己决定——它不影响运行，只是为了让你更容易区分。

条件分为三种类型：

* **按生命值（HP）：** 例如，你的坦克西格德经常被打残。你可以创建一个规则：*“如果西格德的 HP 低于 35%，则选择带有奶妈（伊雅丽）的阵容”*。核心原则：**务必在能够治疗该泰坦的属性房间里**设置回血拦截规则！（对于西格德来说，就是水属性房间或混合房间）。

* **按能量：** 这对“一波流（快速爆发）”阵容至关重要。比如，你的安格斯在土属性房间里，一个大招几秒钟就能秒杀敌人，不给对方出手机会。但前提是他必须带着满能量进入战斗。为此可以创建规则：*“如果安格斯的能量低于 97% — 停止机器人”*。机器人走到土属性房间前会发出提示音并停下来，方便你手动进入混合房间给安格斯攒能量。

* **按敌方阵容（针对性阵容/克制包）：** 如果你极度讨厌敌方的阿拉基（他会融化你的队伍），可以设置规则：“如果敌方有阿拉基，则换上我的专属克制阵容”。

**3. 智能选项（跳过与热身）**

规则构建器里有一些复选框，能防止你的泰坦“愚蠢白送”：

* **禁止进入房间 (Skip/跳过)：** 假设西格德只剩 10% 的 HP，而眼前是一个混合房间。如果强行进去，西格德必死无疑。此时你可以勾选“Skip（禁止进入）”条件并设置为“HP 低于 20%”。机器人看到残血的西格德后，会忽略这个混合房间，转而去寻找水属性房间来给他回血。

* **要求泰坦热身（磨合）：** 这是针对新一天开始的独家神技！早上，所有泰坦的 HP 都是 100%，但能量是 0%。如果直接让他们进高强度的混合房间，他们可能还没来得及开大招就暴毙了。勾选“热身”等于告诉机器人：“该泰坦必须先在其本命属性的简单房间里至少打上一场，攒够能量（蓝量），然后才能派去混合房间。”

**4. 优先级：谁说了算？**

如果西格德血量见底，但偏偏对面又站着可怕的阿拉基，机器人该听谁的？
机器人会像真人一样，**严格自上而下**地读取你的规则列表。

点击灰色按钮 **“查看/删除活动规则”**。在里面你可以看到机器人的判断逻辑。它是这样分组排序的：

1. **首先执行“Skip”规则**（不让残血泰坦进入战斗）。
2. **其次是 HP 和能量救场规则**。
3. **接着是针对特定敌人的克制阵容**。
4. **最后是基础阵容**（在没有触发任何威胁的情况下）。

在这个窗口中，你可以使用箭头（上/下）调整规则的顺序。列表中越靠上的规则，机器人的优先级就越高。调整顺序后，千万别忘了点击那里的绿色按钮 **“保存更改”**。

**5. 重要提示：机器人是如何保存记忆的**

机器人的界面设计旨在避免频繁写入你的硬盘，从而保证极快的运行速度。

1. 当你配置完规则后，一定要在主屏幕上点击**紫色的“保存配置”按钮**。
2. 当你点击“开始挂机”时，机器人会**一次性**读取所有规则并将其加载到内存（RAM）中。
3. 如果机器人已经在挂机，而你中途临时修改并保存了规则——机器人是看**不到**这些新规则的！你必须先点击“停止”，然后重新启动“挂机”，好让机器人“重新读取”新的配置。

**➡ “恢复 / 重置”按钮：** 如果因为突然断电或系统崩溃导致配置文件损坏，只需在开始挂机前点击这个红色的按钮。机器人会自动调取备份文件并修复一切。

**6. 全局安格斯控制**

主屏幕上特别设计了 **“手动控制安格斯大招（全局）”** 的开关。机器人在控制安格斯时的表现比大多数玩家都要好：它能精准等待 1.8 秒，确保“根须”造成最大伤害，然后立即关闭大招。如果勾选了此项，机器人将在**所有**有安格斯上场的战斗中应用此技巧，不论是基础阵容还是特定条件拦截。但在启用此选项前，请务必确保安格斯在开打前已经充能到了 100% 的满能量。

*开发者的秘密：为什么机器人经常暂停，以及如何实现 100% 的全自动？*

刚开始运行的时候经常会遇到这种情况：泰坦的血量看着还很健康，但机器人却频繁暂停游戏，弹出 SOS 窗口问你该怎么办。感觉它好像在无缘无故地恐慌。

这一切都是因为 **“HP 损耗差值 (Delta)”** 这个设置（在主屏幕上）。
差值（Delta）是为了防止单场战斗中受到突如其来的巨额伤害。例如，你设置的差值是 30%。如果你的泰坦带着 100% 的血量进入房间，出来时变成了 69%（损失了 31%），机器人会立即暂停。哪怕 69% 的血条还是绿色的，完全没有生命危险，它也会停下来。

**如何告别烦人的 SOS 窗口，让机器人完全自主运行：**

1. **放宽“差值”限制（懒人专属）：** 如果你觉得频繁的拦截很烦，并且对自己的泰坦实力很有信心，可以直接把“HP 损耗差值”调到 100%（相当于关闭该功能）。这样一来，机器人就不会去计算单场战斗的掉血量，而**仅仅**参考“HP 恐慌阈值”——也就是说，只有在血量真正掉到危险的极低值（例如低于 25%）时，它才会停下来。

2. **把暂停变成经验：** 每次弹出 SOS 窗口，都是进入“规则大师”添加条件的好机会，好让机器人下次知道该如何规避这些伤害。

3. **善用分析功能（通往全自动的必经之路）：** 这是最关键的一点！每次挂机结束，一定要去“分析”标签页运行一次日志分析。机器人会自动找出规律，并为你推荐**“黄金规则”**（经过实战验证的必胜阵容）。你只需要点击“应用”即可。

**总结：** 机器人学习的“黄金规则”和手动设置的条件越多，它打扰你的次数就越少。久而久之，它就会根据你的泰坦养成度建立起完美的知识库，实现 **100% 的全自动托管**！



## 第四部分：防暴毙机制（HP 与 SOS 设置）

机器人绝不会擅自让你的泰坦白白送死。每场战斗结束后，它都会仔细观察血条。在“规则大师”标签页中，有两个核心的安全设置：

* **HP 恐慌阈值（例如 40%）：** 这是绝对的底线。如果战斗结束后，任何一个泰坦的血量低于 40%，机器人就会发出警报。
* **HP 损耗差值（例如 30%）：** 这是针对突然大掉血的保护机制。如果泰坦带着 100% 的 HP 进场，出来时只剩 60%，那么他损失了 40%（这就是 Delta 差值）。如果你设置的单场允许损耗上限是 30%，即使他现在血量还算多，机器人也会暂停游戏。

**SOS 系统（救场菜单）：**
如果触发了“恐慌值”、“差值”或有泰坦阵亡，机器人会暂停游戏并弹出含有三个选项的窗口：
* **手动通关：** 机器人会撤退并重置战斗，由你自己手动通关该房间。
* **回滚战斗：** 机器人会取消战斗，让你可以选择其他阵容重新尝试。
* **忽略：** 你告诉机器人：“没事，我接受这个损耗，直接进下一个房间”。



## 第五部分：Telegram 消息推送

机器人挂机刷图时，你可以放心地去喝茶或散步。一旦泰坦命悬一线，机器人会直接把截图和控制按钮发送到你的 Telegram 上！

* **第一步：** 在 Telegram 中找到官方机器人 **@BotFather**。发送指令 `/newbot`，给你的机器人起个名字，然后复制生成的长代码 `Token`。
* **第二步：** 找到 **@getmyid_bot** 机器人。点击 Start 并复制你的用户 ID 数字（`Your user ID`）。
* **第三步：** 回到第一步中你创建的新机器人的聊天窗口，**务必**点击一下 **“START”（开始）** 按钮。
* **第四步：** 在我们软件中打开“规则大师”，点击 **“配置 Telegram”**。粘贴你的 Token 和 Chat ID，点击“应用”并“保存配置”。



## 第六部分：分析与自我学习

机器人会在后台默默记录你的每一场战斗：谁和谁交了手，以及剩余多少 HP。

进入“分析”标签页，点击“开始日志分析”。机器人会为你计算每套阵容的胜率（成功通关的比例）。如果它发现某套阵容在对付特定敌人时胜率能稳定在 80% 以上，就会将其标记为 **“黄金规则”**。
点击“应用”，机器人就会永远记住这个制胜套路！



## 第七部分：统计与数据同步

机器人拥有精美的统计界面：绘制图表、统计获得的泰坦石、通关房间数和泰坦药水数量。

**关于游戏时间的重要提示：** 
《英雄战争》的新一天会在早上 05:00 开始。请务必在“规则大师”中设定好你的“每日重置时间”，以免机器人把傍晚和深夜的战斗搞混。

**智能同步功能：**
假设你早上自己在手机上手动打了游戏，拿到了 60 个泰坦石。晚上你启动了机器人。机器人该如何了解你的整体进度呢？
非常简单！进入“统计”标签页，选择日期（今天），然后在输入框中输入你在游戏里看到的**泰坦石总数**（例如 150）。机器人很聪明：它知道自己刷了 90 个，它会自动用 150 减去 90，然后把你自己手打的 60 分完美地补录到统计数据中，并据此推算相应的房间和药水产出。系统内置防错保护——机器人不会允许你输入比它自己刷出来的还要低的数值。



## 第八部分：电脑快捷键

* **Ctrl + Q（温和暂停）：** 机器人不会在战斗中途丢下游戏不管。它会优雅地解决完眼前的敌人，领完奖励，并在下一扇门前停下等待。
* **Ctrl + Shift + Q（紧急停止）：** 立即强制关闭机器人。在出现任何意外状况时使用。
