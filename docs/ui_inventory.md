# Сверка нового интерфейса: старое окно ↔ макеты ↔ бот (задача 15)

Составлена 22.10.2026 по коду `ui/*.py`, `main.py` и макетам `design/mockups/`, `design/screenshots/`.
Ответы пользователя внесены 22.10.2026 (вторая часть сессии шага 1).

**Зачем.** Макеты рисовали по описанию, не глядя в код. В них может не быть того, что старое окно уже умеет,
а может быть то, чего бот не умеет. Поэтому:
- что умеет окно — решают старое окно и бот, как оно выглядит — решают макеты;
- перед каждым шагом смотрим свой раздел этой сверки;
- строки с пометкой **вопрос** решает пользователь: Claude пишет варианты и что рекомендует, ответ вносится сюда;
- старую функцию молча не выкидываем, новую логику в бота без разрешения не добавляем.

Пометки: **есть** — в макете есть, делаем по макету; **новое** — в макете есть, в старом окне не было (только интерфейс);
**вопрос** — нужно ваше решение; **ошибка** — ошибка старого окна, в новом исправляем; **решено** — ответ получен.

## 0. Связь окна и бота — не ломать

Окно и бот — два процесса. Бот печатает строки, окно их читает. Окно пишет боту одну строку в stdin.
Новые кнопки шлют те же команды, что и старые. С шага 3 это проверяет тест на поддельном боте (`tests/test_bot_link.py`),
и он прогоняется на каждом следующем шаге.

**Бот → окно** (окно ищет метку через `in`, время в начале строки допустимо):

| Строка бота | Что делает окно сейчас (`ui/dashboard.py`) |
|---|---|
| `[SOS_TRIGGER] {"titans": {...}, "is_manual": ...}` | окно «Требуется вмешательство» + SOS в Telegram |
| `[SOS_TRIGGER] {"type": "NO_VALID_TEAM", "room", "enemies", "reason"}` | окно «Нет подходящего пака» |
| `[SOS_TRIGGER] TEST_SUCCESS:{"titans": ..., "source": "gui"/"telegram"}` | окно «Тестовый пак выиграл» или вопрос в Telegram |
| `[SOS_CLOSE] текст` | закрыть все окна SOS, выбора пака и опрос Telegram; ответы из старых окон не слать (`sos_epoch`) |
| `[ПАУЗА ОТЛАДКИ]` | включить кнопку «Продолжить» (шлёт пустую строку) |
| процесс бота закончился | «Процесс бота завершён», кнопки в начальное состояние |

**Окно → бот:**

| Команда | Откуда |
|---|---|
| `IGNORE` | «Игнорировать (Продолжить)» в окне SOS, ответ из Telegram |
| `MANUAL` | «Пройти руками» (окно SOS, «Нет подходящего пака», Telegram) |
| `ROLLBACK:титан1,титан2,...` | «Откатить бой» → выбор пака; «Откатить и попробовать» в окне тестового пака |
| `ROLLBACK_TG:...` | пак, присланный из Telegram |
| `CONFIRM` | «Утвердить и сохранить» тестовый пак (окно или Telegram) |
| `NEW_PACK:...` | бот умеет («Нет подходящего пака»), **окно сейчас не шлёт** — см. раздел 3 |
| `STOP` | бот умеет («Нет подходящего пака»); окно вместо этого убивает процесс |
| пустая строка | «Продолжить» после `[ПАУЗА ОТЛАДКИ]` |

**Ещё:** файл `pause.flag` (мягкая пауза), `HEROWARS_LANG` (язык), запуск `python -X utf8 -u main.py` / `<exe> --bot-mode`,
калибровка окна scrcpy 1606×748 перед стартом, `bot_data/sos_info.json` (комната, враги, причина для Telegram),
`bot_data/temp_sos.png`, `bot_data/temp_test.png` (скриншоты для Telegram), окно бота следит за окном scrcpy раз в 2 с
(закрыли scrcpy — бот останавливается).

## 3. Окна вмешательства (макетов нет — рисуем в стиле макетов, сначала скриншот на согласование)

| Окно | Кнопки сейчас → команда | Решение |
|---|---|---|
| «Требуется вмешательство» (плохой бой) | «Пройти руками» → `MANUAL`; «Откатить бой» → выбор пака → `ROLLBACK:...`; «Игнорировать» → `IGNORE` | рисуем заново, команды те же |
| то же, если бой шёл вручную (Ангус) или откатить нельзя | «Откатить бой» заменяется на «Остановить бота» (процесс убивается) | то же |
| «Нет подходящего пака» | «Пройти руками» → `MANUAL`; «Игнорировать» → `ignore`; «Остановить бота» | **ошибка 3.1** |
| «Тестовый пак выиграл» | «Утвердить и сохранить» → `CONFIRM`; «Откатить и попробовать» → выбор пака → `ROLLBACK:...` | рисуем заново; если пак пришёл из Telegram — вопрос уходит в Telegram, как сейчас |
| выбор пака для отката | «Откатить и пойти этим паком» | **ошибка 3.2** |

- **Ошибка 3.1 — решено, как рекомендовано.** В окне «Нет подходящего пака» «Игнорировать» шлёт `ignore` маленькими буквами, а бот там ждёт только `MANUAL`, `NEW_PACK` или `STOP`.
  «Собрать новый пак» (`NEW_PACK`) бот умеет, а окно эту кнопку не показывало. Теперь кнопки: «Пройти руками», «Собрать новый пак», «Остановить бота».
  В Telegram у этого окна тоже нет «Продолжить» (`telegram_report.sos_keyboard`).
- **Ошибка 3.2 — решено, как рекомендовано.** Крестик окна SOS и крестик окна выбора пака сейчас **убивают бота**. В новом окне крестик
  окна SOS спрашивает «Остановить бота?», а закрытие окна выбора пака возвращает к окну SOS.
- **3.3 Что показать в окне — решено, как рекомендовано.** Причина, комната, враги (квадраты титанов: картинки возьмутся из `assets/icons/<титан>.png`,
  когда вы их положите, рамку цветом стихии рисует программа) и ваш пак — полоски ХП «до → после», красным — ниже порога паники (общего или личного).
- **3.4 Таймер — решено: обратный отсчёт** «Если не ответить, бот решит сам через 9:41» (`sos_timeout_minutes`, каким его прочитал бот при запуске;
  0 — строки нет). Меньше минуты — строка жёлтая. В окне «Пак справился» — «бот сохранит пак сам через …» (так бот и делает).
- **3.5 Telegram — сделано (шаг 3).** SOS и проверка пака из окна — с повторами при обрыве связи: 30 с, 1, 2, 5, 10 мин, как тревоги бота
